# Screenshot feature mapping — AscendAPP 0.8

|---|---|---|
| Compact meter | Sole startup meter, icons, settings, history, menu, player details, minimize/close | New live fields need in-game verification |
| General | Launch capture, adapter/VPN compatibility, English, report region | No automatic update service or alternate language pack |
| Combat | Idle timeout, boss reset, targeting, party filter, explicit dummy IDs and parse length | Automatic dummy catalogue identification not included |

| Audio | Independent volumes, generated chime and preview | Audible verification remains |
| Buff tracking | Manual class presets, visibility, start/cancel, duration and ready alerts | Automatic buff/effect messages not verified |
| Event tracking | Custom offset-aware reminders, repeat, multiple lead times, timer visibility and alerts | No verified Global schedule |
| Keybinds | Real configurable global hotkeys, conflicts reported, tray recovery | No expanded-view toggle (one meter only) |
| Account | Local character ticket history | No account service |
| Integrations | Local replay, JSONL, CSV and diagnostic export | No uploads or third-party account integration |
| Changelog / Debug | Actual AscendAPP changes, capture stages, labelled demo and diagnostics | No new actual packet fixtures |
