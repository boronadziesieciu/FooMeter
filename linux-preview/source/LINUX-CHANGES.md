# Linux expanded UI update

Rebuilt the Linux interface on the uploaded FooMeter 0.10.29 core:

- Compact borderless combat overlay, class icons, healing view, strip mode, colors,
  scale, opacity, privacy, position lock and boss HP/forecast displays.
- Persistent settings in eight tabs, with import/export and manual score fallback.
- Separate capture controls with saved adapter/port and automatic restart.
- Complete skill lists with sorting and a per-second damage graph.
- Searchable fight history with comparison, confirmed deletion, JSON/CSV export
  and chat copy.
- Separate events and pets windows, independent appearance/positions, all 207
  pet portraits, pinning/filtering and packet-derived soul pickup cards.
- Local reminders, timer notifications, tray controls, single-instance command
  socket, Hyprland binding commands and X11 click-through/Alt restoration.
- Opt-in grim/slurp/Tesseract loot-row recognition and transparent counters.
- Kept the original Windows solution and source unchanged.

Validation and desktop-specific limitations are described in README-LINUX.md.
Original README.md, START-HERE.txt and VERIFICATION.json describe the historical
Windows source release, not validation of this Linux rebuild.
